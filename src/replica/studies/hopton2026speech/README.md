## Abstract

Although language is predominantly spoken, empirical tests of surprisal theory rely almost entirely on written text. In practice, surprisal is estimated using language models (LMs) trained on text and applied to transcriptions, creating a text bottleneck that limits evaluation of the theory in the spoken modality. We remove this bottleneck by estimating surprisal directly from the speech signal using a speech LM. This raises a key question: should surprisal be defined over realization-specific acoustic inputs or over abstract linguistic units? Since a single unit can have many distinct acoustic realizations, each assigned a different probability by the model, defining surprisal over abstract units is difficult. To address this, we introduce an importance sampling estimator that approximates the probability of an abstract unit by marginalizing over realizations generated by a text-to-speech model. Using pupillometry data from a listening study, we evaluate surprisal theory in this text-free setting at multiple levels of granularity. Obtaining surprisal from several speech LMs, we consistently find that surprisal estimated via importance sampling better predicts pupil dilation than realization-specific surprisal for words. We also find that surprisal values for sub-lexical units are predictive of pupil dilation. While we find that surprisal can be estimated without recourse to text, and that marginalizing over distinct realizations of words is more predictive of lexical processing effort, surprisal as a whole is not a strong predictor of change in pupil size, regardless of its source.

## Predictors

Realization-specific surprisal is evaluated at word, phone and frame levels.
Importance-sampled word surprisal marginalizes over acoustic realizations.
The models include the previous unit's surprisal and predict proportional
change in pupil size in the Winn (2016) listening study.

Speech models are GSLM, SpiRit-LM and Llama-Mimi (1.3B and 8B), with GPT-2 as
a word-level text baseline. The analysis uses 162 Revised Speech-in-Noise
items (lists 3–6) from 21 normal-hearing listeners in non-vocoded trials.

## Reproduction

Install the [R backend and its dependencies](../../../../docs/guides/environment.md#optional-capabilities),
including `mgcv`, then download the study inputs:

```bash
replica results fetch hopton2026speech --verification
```

The study loads checksum-verified pupil, predictor and fold tables. Downloaded
inputs are cached. Original audio and speech-model inference are not required
to refit these tables.

These bundles support refitting saved predictors. Regenerating predictions from
audio and rerunning the estimator-variance experiment require additional inputs
that are not included here.

Run one model and surprisal condition:

```python
from replica import evaluate
from replica.studies.hopton2026speech import Hopton2026Speech

study = Hopton2026Speech()
options = dict(model="gslm", granularity="word", variant="marg", offset=1000)
dataset = study.dataset(**options)
spec = study.evaluation_spec(dataset=dataset, **options)
result, = evaluate(dataset, spec, study.analysis_config(**options))
print(result.delta_ll_per_unit)
```

`model` accepts `gpt2`, `gslm`, `spirit`, `llamamimi` and `llamamimi8b`.
`granularity` accepts `word`, `phone` and `frame`; GPT-2 is word-only.
`variant="marg"` selects importance-sampled word surprisal for speech models;
`variant="unmarg"` selects realization-specific surprisal.
Offsets are 900, 1000 and 1300 ms. Pass `time_smooth=True` to both
`evaluation_spec()` and `analysis_config()` for the appendix time-smooth model.

The recipe fits generalized additive mixed models with ten-fold item
cross-validation, using the paper's fixed fold assignments. Predictors are
standardized over each complete analysis cell. Scoring retains fitted listener
effects, uses zero effects for unseen items and estimates each model's residual
scale from all held-out predictions. These choices reproduce the paper's
analysis; the reported gain is the mean held-out delta log-likelihood in nats.

The [reference tests](../../../../tests/studies/hopton2026speech/test_hopton2026speech.py)
check observation counts, word coverage, 51 model/offset means and 17 appendix
time-smooth means against the [saved reference tables](../../../../tests/studies/hopton2026speech/fixtures).
Bootstrap confidence intervals, significance marks and the paired
marginalized-versus-unmarginalized contrast are not recomputed by this recipe.
